Проект: Phygital Poker (Telegram Mini App)

1. Основна концепція
   Гібридна гра, де Дилер використовує фізичну колоду та камеру (з акцентом на Apple Desk View), а Гравці беруть участь дистанційно через HUD-інтерфейс (Heads-Up Display) у Telegram.

2. Технологічний стек
   Frontend: React + TypeScript + Vite.

Транспорт: Socket.io (для миттєвих команд) + WebRTC (для відео-стримінгу столу).

Платформа: Telegram Mini Apps (TMA) SDK.

Computer Vision: TensorFlow.js або OpenCV.js (локально на пристрої дилера).

Infrastructure: Node.js (Backend), ngrok/Cloudflare Tunnel (для розробки).

3. Компоненти системи
   А. Модуль дилера (Scanner Node)
   Camera Engine: Захоплення потоку з Desk View (вигляд зверху).

Scan Zone: Фіксована область у центрі екрана для розпізнавання.

State Machine: Перемикач режимів:

Роздача гравцю: (Вибір гравця -> Сканування -> Надсилання в HUD).

Стіл: (Вибір стадії Флоп/Терн/Рівер -> Сканування -> Візуалізація для всіх).

Confirmation UI: Підсвітка рамки (зелений/червоний) при успішному зчитуванні карти.

Б. Модуль гравця (Remote HUD)
Background Layer: Прямий відео-ефір ігрового столу.

HUD Overlay: Цифрові шари поверх відео:

Приватна зона: Твої дві карти внизу (отримані від дилера).

Спільна зона: Оцифровані карти столу (дублюють фізичні для кращої видимості).

Ставки: Кнопки Bet/Fold/Raise, що лежать поверх відео.

В. Backend (The Pit Boss)
Rooms Management: Створення столів за ID.

Event Bus: Роздача повідомлень: «Гравець А отримав карту», «Банк зріс».

Security: Шифрування даних карт (щоб ніхто не підглянув у Network Tab).

4. Робочий процес (Data Flow)
   Дилер кладе карту в Scan Zone.

Frontend (AI) розпізнає масть та номінал (наприклад, Ah — Ace of Hearts).

Socket.io відправляє зашифрований сигнал: { target: "player_1", card: "Ah" }.

Гравець 1 отримує сигнал, і в його HUD з'являється анімована карта Туза Чирви.

Відео-потік підтверджує фізичну наявність цієї карти на столі.

5. Найближчі кроки (Roadmap)
   Setup: Реєстрація бота, запуск React + ngrok.

Vision Prototype: Реалізація «вирізання» картинки із зони сканування (Canvas Crop).

Logic: Простий алгоритм визначення кольору карти (червона/чорна).

Sync: Налагодження зв'язку «Дилер -> Сервер -> Гравець».
